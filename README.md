# وداعاً للألم (30minutes30) - نظام الشات بوت والذكاء الاصطناعي وبوابة المراجعين الملكية 👑

نظام متكامل لإدارة الاستشارات والتواصل الطبي مع المراجعين، متخصص في العلاج الطبيعي وتقويم العمود الفقري والمفاصل (الكايروبراكتيك) لمركز **وداعاً للألم** في عمّان (خلدا) ومحافظة الزرقاء.

---

## 🌟 محتويات المشروع:

1. **`royal_patients.html` (بوابة المراجعين الملكية وغرفة عمليات البرودكاست):**
   * كروت VIP ملكية فخمة لكل مريض مستخرج.
   * ختم الشكوى السريرية المشخصة (ديسك، عرق النسا، كهربا بالأرجل، خدر وتنميل).
   * استخراج وجمع أرقام الهواتف وتصدير ملف جهات الاتصال (`vCard / .vcf`).
   * منصة إطلاق حملات البرودكاست والرسائل الجماعية عبر الواتساب مع 4 قوالب نفسية وطبية جاهزة.

2. **`index.html` (محاكي الشات بوت وماسنجر فيسبوك):**
   * شات بوت ذكي مبرمج وفق هندسة الإقناع النفسي والتعاطف الطبي.
   * زر "📋 جمع البيانات" لحفظ الاسم، الهاتف، والشكوى بضغطة زر.
   * ماسح أرشيف ماسنجر الشامل (Historical Archive Scanner) لسحب كافة المحادثات السابقة لصفحة فيسبوك.

3. **`facebook_server.js` (خادم الـ Webhook السحابي المباشر):**
   * سيرفر Node.js / Express جاهز للربط المباشر مع Meta Graph API (فيسبوك وإنستغرام).
   * يعمل 24/7 لاستقبال رسائل المراجعين والرد عليها تلقائياً.

4. **`cloudflare_worker.js`:**
   * سكريبت سحابي خفيف بدون خادم (Serverless) للاستضافة المجانية على Cloudflare Workers.

---

## 🚀 التشغيل والنشر:
* **محلياً:** افتح ملف `index.html` أو `royal_patients.html` في أي متصفح ويب.
* **على السيرفر السحابي (Render / Glitch / Railway):**
  * `npm install`
  * `npm start`
* **معلومات التحقق للـ Webhook في فيسبوك:**
